# DuoplesOS ROM

DuoplesOS source manifests, device configurations, and vendor packages for building DuoplesOS on LineageOS 23.0 / Android 15+.

## Supported Devices
- **Xiaomi Redmi Note 7 Pro (`violet`)**

## Structure
- `manifests/`: Repo local manifests
- `device_violet_patches/`: Product and device configuration makefiles
- `vendor/duoples/`: Branding, versions, and custom apps
- `crave_build.sh`: Automated Crave build script
